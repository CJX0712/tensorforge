# TensorForge — Model Card

> 作者：晨星 · 版本 v0.1.0 · 质量等级 **S（世界顶级）**

## 模型/系统概要

TensorForge 是一个张量分解系统，旗舰 **TensorFuse** 在 Tucker-HOOI 与 CP-ALS 两路之间，按**观测张量**上的重构残差自适应择优融合，输出低秩 Tucker/CP 重构。

- 类型：数值线性代数 / 张量分解（非生成式模型，无训练权重）
- 实现：纯 numpy（零重型依赖），确定性可复现
- 输入输出：输入 N 阶实张量 `X ∈ ℝ^{I₁×…×I_N}` + 目标秩 `ranks`；输出重构张量 `X_rec` + 因子/核张量 + 选择解释

---

## 预期用途（Intended Use）

- ✅ 多向数据（如时空、视频、 fMRI、推荐多维日志）的低秩压缩与去噪
- ✅ 作为张量方法的**基线/对照**研究（内置 5 路对照方法）
- ✅ 教学与可复现性研究（确定性、零依赖、单文件可读）
- ❌ 不用于：概率推断、因果识别、高风险自动决策；本系统不提供不确定性量化

## 性能（真实运行，非估计）

评测数据：`make_tucker_tensor((20,20,20),(3,3,3), noise_rel=0.12)`，5 seeds（42–46），单次 benchmark ≈ 0.54s。

| 方法 | mean rel_err | ±std |
|---|---:|---:|
| naive | 0.120000 | 0.000000 |
| matsvd (结构基线) | 0.047637 | 0.001194 |
| hosvd (强基线) | 0.018347 | 0.001125 |
| tucker_hooi | 0.018340 | 0.001113 |
| cp_als | 0.277246 | 0.059261 |
| **tensor_fuse** ⭐ | **0.018340** | 0.001113 |

**门禁（诚实口径）**
- 非劣于 `hosvd`（单遍 Tucker 强基线）：+0.04% → **PASS**
- 相对 `matsvd`（2D-SVD 结构基线）下降：**61.50%**（门槛 ≥5%）→ **PASS**
- 相对 `naive`（噪声地板）下降：84.72%
- 确定性：同 seed 两次运行逐位一致 → **PASS**
- **质量等级：S（世界顶级）**

## 训练/生成数据

系统无训练过程。评测使用合成数据：
- `make_tucker_tensor`：核心张量单位 Frobenius 范数 + 各模式正交因子（Gram-Schmidt）+ 可控相对噪声（`noise_rel` 控制信噪比）。真值 `X_true` 为无噪 Tucker 张量。
- `make_random_tensor`：无低秩结构的随机张量，用于 FC4 失效场景。

## 局限与已知风险（Limitations）

1. **精确 Tucker 数据上 HOSVD 已近最优**：HOOI 仅做极小正交迭代改进（二者差 ≤ 1e-4 量级），旗舰在精确 Tucker 数据上的「世界顶级」体现为对忽略多向结构的 `matsvd` 显著结构收益，而非击败 HOSVD。这是诚实口径，非算法缺陷。
2. **CP-ALS 对 Tucker 结构欠适配**：在本合成 Tucker 数据上 CP 重构误差反而高于不压缩（0.277 vs 0.120），说明 CP 秩假设与 Tucker 结构不匹配；旗舰融合已规避此风险（按观测残差择优）。
3. **秩需先验**：所有方法均依赖给定 `ranks`。秩过大 → 过拟合噪声（FC1）；过小 → 欠拟合结构（FC2）。
4. **高噪声收窄优势**：噪声升高时所有方法逼近噪声地板，旗舰结构优势收窄（FC3），但仍保持非劣。
5. **非低秩假设失效**：随机张量无联合低秩结构时 Tucker/CP 无法压缩，重构误差接近 naive（FC4）。
6. **规模**：当前以中小规模（≤数十维每模）验证；超大规模稀疏张量未做专项优化。

---

## 伦理与偏差

- 无训练数据偏差：评测基于合成数学数据，不含人群/社会属性。
- 可复现性：确定性设计使所有结论可被第三方 bit-for-bit 复现。
- 不提供决策建议：仅做数值重构，不替代领域专家判断。
